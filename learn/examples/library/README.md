# Example Library

This folder shows what `get-started-stinger` can create in another repository. Do not store new Vibe Coding Tools project requirements or knowledge here.

## Layout

| Folder | Purpose |
|---|---|
| `knowledge/public/` | Customer-safe overviews, guides, and FAQs |
| `knowledge/private/` | Internal architecture, standards, operations, and ADRs |
| `requirements/` | PRDs moving through backlog, in-work, and completed |
| `issues/` | IRDs for bugs and incidents using the same lifecycle |
| `notes/` | Human-owned scratch notes |

Read [`documentation-framework.md`](knowledge/private/standards/documentation-framework.md) for the complete standard. Read [Library Structure](../../guides/LIBRARY-STRUCTURE.md) for a plain-language explanation.

To create a live library, open the target repository and ask your assistant to use `get-started-stinger`. The skill inspects existing content and creates only missing pieces.
