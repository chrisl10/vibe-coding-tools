# Fictional example: Beacon Research

Beacon Research is a made-up multi-workspace app that accepts a public URL, captures evidence, creates a cited brief and shows progress. It exists only to demonstrate App Primer Zero's preparation artifacts. No company, code donor, customer, provider account or runtime result is represented.

## Selected example direction

For illustration, the app accepts a request, stores evidence and produces a cited brief. The storage engine, interface, runtime, providers and model are unbound. A hypothetical harness has a supplied three-slot ceiling, unverified: one integrator plus at most two implementers. Security and Quality later reuse one review slot in separate waves.

## Baseline state

An example repo contains a manifest, visual prototype and brief. Routes, job execution, migrations, provider clients and native checks are missing. Two proposed contracts are Draft: scoped intake and evidence/output readiness. Neither the selected architecture nor this example accepts their detailed terms.

Read [the foundation baseline](foundation.md), [schema coverage](schema-ledger.md), [boundary map](contracts-and-seams.md), and [wave handoff](wave-handoff.md). The [machine-readable fixture](../../templates/wave-plan.example.json) uses an illustrative SHA and `example: true`; it must not become a ready implementation plan by changing only the approval strings.

## What a coordinator does

Inventory real files, resolve core methods, draft exact interfaces and full source-field mapping, then obtain the owner decisions that affect execution. Produce a runnable-foundation lane and independent adapters against accepted DTOs. First prove input -> scoped commit/outbox -> durable acquisition/generation -> scoped progress -> cited artifact, including retry and failure cases, before expanding the feature set.

The exercise's exit is a coherent planning handoff with explicitly blocked future implementation. No schema, model, provider, concurrency engine or app is claimed tested by the fictional prose. The JSON validator's structural pass is a separate observed check of the fixture.
