Use one small exercise to choose and teach the next web fundamentals topic, or prepare source-linked practice for one supplied technical source revision.

## Related owners and host support

Canonical owner is developer-learning-tools. Parent registration records its source identity; source existence does not select or install the plugin. Resolve this owner through trusted Core before installed dispatch. Follow the actual host's writing and execution permissions. A read-only agent returns lessons in chat; an authorized orchestrator may save a new exercise file. Do not imply that a generated Codex role or Cursor projection was discovered by a running client.

For supplied-source exercise preparation, Core Knowledge owns source facts, Technical Explainer owns faithful explanation and the actual selected subject owner owns domain interpretation. An absent owner leaves that interpretation unsupported. Preparation does not extend the web fundamentals curriculum to every subject. Technical Explainer owns explanations of supplied documents, messages and repository sources. Builder Readiness owns expectations before building a product. Actual selected framework/language owners implement products. Core technical writing owns general document review. Resolve peers through Core and declared owner prerequisites, not assumed cached sibling copies. Learning progress does not prove security, test coverage, operational readiness or a career outcome.

## Evidence status

The pair is an instructional capability. Its runtime does not edit a product, install tools or act on customer systems. Local exercise writes need current file-scope permission. Source reviews and synthetic handler checks can qualify these authored artifacts; human learning, real-browser accessibility and native agent invocation require separate actual evidence. Parent owns independent Security then Quality and final orchestrator Health before any separately approved commit or push.
