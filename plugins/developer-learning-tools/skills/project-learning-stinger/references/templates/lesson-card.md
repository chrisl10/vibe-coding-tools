# Lesson card

The lesson card describes one practice behavior and its evidence.

- Outcome: one observable learner action.
- Prerequisites: only knowledge and tools used in the lesson.
- Starting files or chat-only example:
- Vocabulary: at most the new terms needed in this step.
- Prediction prompt:
- Small edit or exercise:
- Expected observable result:
- First hint, without the full answer:
- Feedback tied to the actual attempt:
- Retry with the same concept:
- Transfer exercise with one new condition:
- Teach-back question:
- Evidence status and scope limits:

Keep the worked solution separate from the exercise prompt. Do not hide answers behind inaccessible interaction. Ask whether the learner wants the answer before revealing it, unless they already requested a worked example.
