| C1 | PENDING | not-attempted | PENDING | PENDING | PENDING | PENDING: no actual attempt |

Actual means supplied by the learner, not inferred from agreement, generated by the tutor or copied from a worked example. In a fictional example all responses retain the FICTIONAL label and all real learner fields remain PENDING.

## Status vocabulary

| Status | Required basis | Scope limit |
|---|---|---|
| DEMONSTRATED_IN_THIS_EXERCISE | Actual response satisfies the named criterion with support recorded | Only this source revision and attempted condition |
| PARTIAL | Actual response satisfies part of the criterion, with the missing behavior named | No implied completion |
| PENDING | Required learner attempt or follow-up is absent | No understanding judgment |
| UNSUPPORTED | Source claim, domain interpretation or required verification lacks evidence | No assessment of that criterion |

Support is independent, hint-assisted, solution-assisted or not-attempted. It describes assistance, not a ranking of people. First attempt, retry, changed condition and teach-back are separate observations. The worksheet is a criterion rubric for practice and formative feedback; it is not a validated scoring scale or a competency or certification assessment.
