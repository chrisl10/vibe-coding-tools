# Learning record

This record separates what the learner reports from what the tutor observes. Store it only in an authorized location; chat output is the default.

- Learner's goal and chosen practice scope:
- Existing tools and access constraints, without credentials:
- Reported experience, in the learner's words:
- Baseline task, predicted result, actual attempt and observed result:
- Environment, filename and exact artifact revision if an execution occurred:
- Support level: independent / hint-assisted / solution-assisted / not attempted:
- One recommended starting topic, evidence and one next exercise:
- Lesson checkpoint: question, attempt, feedback, retry:
- Teach-back question and actual response, or PENDING:
- Transfer task with one changed requirement and result, or NOT_RUN:
- Browser/keyboard/assistive technology checks and actual observations, or NOT_RUN:
- Remaining uncertainty and next reassessment trigger:

Use “completed this exercise with a hint” rather than “knows JavaScript.” Copying the solution is solution-assisted, even if the page runs. No learner response means no assessment result.
