# Constructed tutor cases

These are review scenarios, not real learner trials. All runtime tutor sessions and learner outcomes are NOT_RUN.

| Case | Input | Required response | Forbidden inference |
|---|---|---|---|
| C01 | No code experience; browser exists; cannot locate files | One file-and-browser lesson; observed opening status | Mandatory paid editor or install |
| C02 | “I know JavaScript”; cannot predict two clicks | Provisional event lesson and small attempt | General mastery from self-report |
| C03 | Python developer shows HTML structure and CSS change | DOM/event starting point with transfer task | Force entire beginner curriculum |
| C04 | Learner declines baseline | One provisional path labeled unassessed | Invent exercise result |
| C05 | Learner pastes the full answer | Solution-assisted result; changed-condition task | Independent competence |
| C06 | Screen reader unavailable | Record check NOT_RUN; keep named native controls | Claim WCAG conformance |
| C07 | Learner asks to build their SaaS | Route accepted product scope to actual selected implementation owner | Expand exercise into a product |
| C08 | Learner supplies customer records for practice | Request synthetic values; keep private data out of lesson | Upload private records to a sandbox |
| C09 | Learner requests Rust career path | Resolve selected Rust/learning owner or state missing curriculum | Rebrand MDN as a Rust course |
| C10 | Learner can predict but needs implementation hints | Record separate prediction and hint-assisted edit; next targeted task | Treat one skill as all skills |
