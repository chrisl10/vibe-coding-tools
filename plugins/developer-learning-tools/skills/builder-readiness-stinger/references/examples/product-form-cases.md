# O024 constructed product-form cases

Seven expected advisory responses, NOT RUN with a learner or product. No platform feasibility or market outcome is established.

| Fictional input | Required recommendation or question | Boundary |
|---|---|---|
| Club wants public meeting dates from a link; no private actions | Provisional website; propose one readable meeting page and navigation behavior | No login/database invented. |
| Team must assign tasks in browsers with private records | Provisional web app; qualify actual access and data behavior with selected owners | No framework ranking or permission proof. |
| Staff must process local files after network loss on named desktop OS | Provisional desktop app; qualify exact file/offline behavior and release channel with selected native owner | No promise web/PWA cannot do it; no native runtime evidence. |
| CRM must receive approved order events from an existing system | Provisional integration; qualify actual sender/API/access and failure contract | No invented vendor API, credentials or account setup. |
| User wants an action inside a named browser host | Provisional host plugin; qualify host API/permissions/distribution | No generic plugin capability guarantee. |
| Developer wants a typed command that checks test files and returns a result | Provisional command-line tool; qualify input/output/error and file scope | No automatic Python/language choice or real execution. |
| "Build me an app, cheapest and fast; I have not said who uses it" | Ask the missing user/job/interface question; independent definitions may continue | No form, universal cost or completion date guessed. |

All cases keep understanding pending. Recommendation is provisional; target-specific qualifications remain with actual selected owners.
