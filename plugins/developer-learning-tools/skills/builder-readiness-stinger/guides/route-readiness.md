# Hand off the decisions without duplicating specialists

1. Resolve actual selected owners through trusted Core. Market Validation researches demand; Web Stack Selection chooses framework; Infrastructure Fit chooses topology; Launch Assets prepares accounts/assets; Estimation forecasts; Pricing/Operating Cost handles money; App Primer structures the accepted app foundation.
2. Send only the relevant worksheet inputs and unknowns to each required owner. Do not invent rates, market conclusions, framework recommendations or asset setup to avoid an unavailable specialist.
3. Technical Explainer helps a learner understand a supplied source. Core Knowledge/Library/contracts handle actual source architecture/plans/shared agreements. Existing repository work follows its actual owners rather than reinitializing it.
4. Record selected, unavailable and pending owners separately. Cached components and staging sources are not registered installed capability. Missing delegation uses truthful direct skill workflow where available, not invented native-role dispatch.
5. Deliver one readiness recommendation, role map, first-slice proposal, understanding status and concrete next handoff. No accounts, installs, app build, settings, paid operation or publication begins implicitly.
