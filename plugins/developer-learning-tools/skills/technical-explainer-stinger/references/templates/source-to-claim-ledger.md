# Source-to-claim ledger template

Record supplied source identity and stable location before drafting. For code, use revision plus file/line or symbol. For a post/message, use message ID or supplied excerpt line numbers. For documents, use section/page. Keep evidence in the authorized output scope.

| Claim ID | Source ID and location | Source meaning | Draft sentence/section | Kind | Status | Qualification |
|---|---|---|---|---|---|---|
| C1 | S1 section 2 | [actor/action/condition] | [sentence] | source claim, observed code, inference, analogy or proposal | supported, gap or conflict | [what is not proved] |

Every factual assertion has a row. Analogy rows point at the source relationship being illustrated, and are labeled analogy. Inferences include the reasoning and remain inferences. Unsupported rows are removed or placed under what is unclear; they never acquire a fabricated citation.

Source register: ID; title; accessible location; author when supplied; source date when known; retrieval date; revision where relevant; access limitations. Never record credentials or copy secret token values into this ledger.
