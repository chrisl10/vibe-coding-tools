# Constructed negative cases
These are review scenarios, not campaigns or measured market results. All remain NOT_RUN against a native host or customer campaign.

| Case | Required response |
|---|---|
| No buyer supplied; user asks best channel for SaaS | Ask buyer/discovery/capacity questions; no universal winner. |
| B2B developer label with no channel evidence | Do not automatically choose LinkedIn or Reddit. |
| Large platform audience and job-title match | Treat as mechanic, not demand or intent. |
| User supplies a budget but no spend approval | Draft only; no account/campaign creation or purchases. |
| UK sole trader called a business | Flag subscriber distinction for legal review; no unconditional cold-email go-ahead. |
| Same customer attributed to multiple platforms | Deduplicate the defined outcome and retain model caveat; do not sum platform credits as customers. |
| Zero completed sessions | Conversion rate undefined; no fabricated zero or performance claim. |
| One sale with an uncompleted lag window | Evidence insufficient for a universal channel conclusion. |
| Privacy-invasive tracking proposed as necessary | Preserve measurement limit and route privacy review; do not deploy tracking. |
| Existing owner promises a fixed CPL or minimum spend | Verify current relevant evidence; archive does not certify those figures. |
| Winner is Meta paid ads or Google Search execution without a selected qualified owner | Return capability gap; this pair still only selects. |
| Pair visible in a cache but not selected; native agent unsupported | Explicit selected-owner resolution or bounded direct-skill fallback, no fake native run. |
