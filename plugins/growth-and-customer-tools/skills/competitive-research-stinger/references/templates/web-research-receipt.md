# Web research receipt

Copy into the authorized run directory. Preserve historical receipts and revisions. This worksheet is analyst-authored, not a new JSON helper schema. Remove secrets and unnecessary personal information from queries, URLs and retained responses; if that prevents adequate provenance, record the limit and ask for an approved evidence location.

Record blocked, unreachable, gated, partial, redirected and unattempted pages even when no capture exists. Retain the actual error/status without inventing a page hash. A source's publisher and a claim's proof class are independent: a vendor's primary documentation can still support only a vendor_claim about behavior.

## Passage support and claim decisions

| Claim id / revision | Exact scoped statement / unit | Class / source ids | Heading + paragraph, line range or page + table cell | Support / qualification / counterevidence | Freshness decision / reviewer / unresolved action |
|---|---|---|---|---|---|
| | | | | | |

Classes follow the existing JSON: vendor_claim, observed, inference, unknown. An actual observation includes method, environment/version/date and artifact. Supplied reviews are attributed experience. Preserve contradictions as separate sourced claims; do not average incompatible prices, scopes or methods. A citation must support the whole sentence, including geography, plan, version and date qualifications.
