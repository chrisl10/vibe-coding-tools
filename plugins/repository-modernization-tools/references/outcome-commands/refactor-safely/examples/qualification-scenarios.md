# Semantic qualification scenarios

| Trigger | Required behavior |
|---|---|
| dead-code scanner says delete | Require manual classification and explicit deletion authorization. |
| baseline tests absent | Prepare characterization through selected language owner before equivalence claim. |
| changed error behavior | Stop behavior-preservation claim; require separate scope decision. |
| unselected Python owner | Stop Python edits and name Backend and Desktop prerequisite. |

These scenarios qualify procedure semantics only. They do not claim live harness execution or application behavior.
