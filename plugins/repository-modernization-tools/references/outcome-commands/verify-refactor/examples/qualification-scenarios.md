# Semantic qualification scenarios

| Trigger | Required behavior |
|---|---|
| no baseline result | Recover authorized isolated baseline or mark equivalence unproven. |
| different benchmark environments | Mark performance inconclusive. |
| browser test substituted for native | Reject native-proof claim and identify missing platform owner. |
| security findings unresolved | Do not run final Quality until fixes and Security re-evaluation. |

These scenarios qualify procedure semantics only. They do not claim live harness execution or application behavior.
