# Semantic qualification scenarios

| Trigger | Required behavior |
|---|---|
| fresh environment not available | Mark setup instructions UNEXECUTED, not tested. |
| private credential required | Record owner action using name only and stop dependent run. |
| README already exists | Audit first and propose bounded edits. |
| first contribution asks to open PR | Prepare local description and ask for explicit external-action authorization. |

These scenarios qualify procedure semantics only. They do not claim live harness execution or application behavior.
