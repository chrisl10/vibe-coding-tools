APPROVED asset metadata is intentionally empty. The worker refuses installation until the actual public build paths, MIME and SHA-256 are reviewed. Copy the policy next to the worker in the real app; adapt exact paths/scope/version under authorized ownership. Manifest icons are empty reference placeholders; target-approved icons and actual installation criteria are still required. The pure policy fixture checks only synthetic request classification, including explicit cookie headers; browser cookie visibility differs and does not establish absence of cookies. Precache fetch omits credentials; no runtime network response is stored.
