# Constructed bounded resource contract
The example supports exact canonical tags en-US and ar only, with approved synthetic default en-US. Direction comes from a fixed table. Resource files are bundled objects, never user-derived paths. A resource has save and itemCount; itemCount is a plural-category object with other. Keys/categories/text are validated, and the sole count placeholder is required in every plural branch. These are example policies, not a universal message-resource standard.
Money has a finite amount and approved currency USD or EUR; locale never changes currency. Date accepts a valid Date instant plus explicit approved UTC or America/New_York timezone. The example makes no persisted preference, legal copy, translation provider, ICU parser, DOM or browser claim. Unknown route locale falls back; dangerous keys, markup resources, wrong placeholders and unknown formatting inputs reject.
