# Implement RTL and review translated interfaces
Grounding: W3C direction, W3C language, MDN logical CSS.

1. Preserve PRODUCT.md, DESIGN.md and the surface brief under the existing Impeccable workflow. Ask for missing approved languages or content reviewer. Hand actual framework bindings to the selected UI/framework owner. Technical font coverage and loading belong to Typography/Font Loading; do not choose new fonts or install subsets here.
2. Set document lang and dir from the approved locale metadata. Preserve characters in logical order. Isolate mixed-direction dynamic text with bdi or tightly scoped dir=auto as appropriate; isolate fixed-direction identifiers intentionally. Do not blanket-strip text, reverse strings or use CSS direction as the only semantic marker.
3. Use logical margins, padding, alignment and inline sizes where intent follows writing direction. Inspect icons, progress, charts, logos, media and numerals individually. Preserve DOM reading/focus order and accessible names. A blanket transform or row-reverse can create a mismatch between visual and interaction order; review the actual surface.
4. Exercise Arabic/Hebrew mixed with Latin identifiers, punctuation, numbers, empty/error states, long translated content and pseudolocalization. Check text expansion, wrapping, focus, keyboard traversal, zoom/reflow and assistive reading on the actual target with the browser/accessibility owner. Static CSS, string tests and Impeccable detector results are separate evidence categories.
5. Require a named qualified language/content reviewer for terminology, grammar, plural context, cultural suitability and critical consent/payment copy. Record source/version, reviewer disposition and unresolved messages. Machine draft/schema parity does not establish translation quality.
6. Capture scoped desktop/mobile LTR/RTL evidence and record browser/locale/viewport. Native platforms require their selected implementation owner and device/assistive evidence. Report NOT_RUN for unperformed checks. Do not claim full accessibility conformance, full RTL coverage or native readiness from this package.
