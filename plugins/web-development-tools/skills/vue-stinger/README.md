## Related owners and host support
Resolve actual selected owners through trusted Core and the current source catalog. Vue owns SFC implementation, composables and client app integration. React owns React; Web Stack Selection owns framework choice. Nuxt SSR, server routes and hydration require a separately selected implementation owner; absence is an explicit gap. Backend auth, data, billing and infrastructure remain with their accepted owners. Security reviews trust boundaries independently.

Impeccable owns design direction through PRODUCT.md, DESIGN.md and surface briefs. Apply existing tokens and accessible primitives when implementing Vue; Vue does not install Impeccable or substitute React/Svelte-only component packages. Route missing Vue primitive/design support back to the orchestrator. Never weaken CSP to adapt a component.

Claude Code/Cowork consume the paired agent source. Cursor gets the separately shaped projection; its frontmatter does not enforce Claude tools or isolation. Codex uses the builder's selected TOML projection and Core registration. Staging files prove no installed discovery, delegation or execution on any host.
