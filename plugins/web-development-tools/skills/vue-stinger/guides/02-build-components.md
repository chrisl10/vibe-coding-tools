# Build components and composables
1. Use the project's accepted SFC style. For the provided templates, use script setup with TypeScript, typed props and declared events. Read props through props.name or a getter passed to the composable; never mutate parent-owned props.
2. Keep computed getters pure. Side effects use explicit watched sources; register cleanup before awaits, abort invalidated requests and suppress late results even if a transport ignores abort. Create lifecycle-bound watchers synchronously in setup.
3. Render loading, empty, success and sanitized failure states. Validate unknown JSON independently of TypeScript. User text uses interpolation; no unsanitized v-html, user templates, event-handler strings or arbitrary user style/URL bindings.
4. Adapt native labeled input/button controls to the existing design contract through Impeccable. Preserve keyboard operation, visible focus, instructions, errors connected by aria-describedby and status announcements. Browser checks must substantiate these claims.
5. Reuse [RecordForm](../references/templates/RecordForm.vue) and [useRecord](../references/templates/useRecord.ts) only after defining the real endpoint, decoder, parent submit state and routing integration.
