# Prepare a reviewable copy plan

Complete [the provenance manifest](../references/provenance-manifest.json) against the exact candidate before application changes. Preserve artifact bytes and fetch URL/date/hash, repository revision, upstream file path and hash, destination path, license texts, copyright headers, NOTICE and third-party source records. Root-license inference never clears file exceptions or bundled material.

1. Enumerate the smallest functional source subset and its import closure. Separate copied files, normal runtime/peer dependencies, registry items, fonts/icons/assets and build-only prerequisites. Check generated outputs and package tarballs when those are the actual delivery artifacts. Do not imply the source tree proves them.
2. Review rights evidence with Software Licensing; retain counsel's unresolved compatibility decisions. Preserve complete applicable notices and actual license texts at the review-approved destinations. Never strip upstream attribution while renaming a component. Local authorship notes are additive.
3. List each intended copy, adaptation, manifest/CSS/config mutation and dependency installation separately. Tie theme changes to approved tokens, behavior changes to the surface contract, and patches to original file hashes. CLI no-deps-install still edits package declarations; overwrite/init flags can replace CSS or components.
4. Show original-to-proposed diff and exact authorized path list to the parent/user. Obtain task-specific authorization before copying or installing. Existing source files and another agent's active work require their own approved scope. An unknown notice destination or dependency closure blocks the dependent copy.
5. Only after authorization, perform the bounded copies in the target repository, record local hashes and modifications, retain notices, then run the target's existing build and meaningful behavior checks. Invoke Impeccable's detector on the actual UI target when available; absent tooling stays NOT_RUN, with no installation workaround.
6. Report Security first, independent Quality second, parent repository health last. Source hashes establish identity, not license compatibility or accessibility conformance. No commit/push/deploy unless explicitly approved.
