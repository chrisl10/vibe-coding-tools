# Styling and component fit worksheet

Record repository path and source revision. Unknown fields stay unknown.

| Field | Evidence or decision |
| --- | --- |
| Framework and versions; rendering mode; build tool | Package manifests and route entry files |
| Supported browsers and devices | Product requirement and compatibility comparison |
| Existing CSS, design tokens, component primitives | Paths and ownership |
| Required controls and interaction behavior | Dialog, menu, form, table, native input or plain content |
| CSS entry and scanned source directories | Explicit paths; package source exclusions |
| Class construction | Literal class map; runtime CSS variable needs |
| Theme mode, selector, persistence and first render | Same contract for server and client; no unguarded server window/localStorage |
| Copied component provenance | Origin, revision, license notices, local changes, update owner |
| Implementation routing | Existing selected owners and missing coverage |
| Recommendation | One choice with reason, disqualifier, and assumptions |
| Qualification evidence | Actual build, rendering, keyboard, contrast and visual checks, or pending |

Complete using [guide 08](../guides/08-component-framework-fit.md). This worksheet authorizes no installation, upgrade, provider change or overwrite.
