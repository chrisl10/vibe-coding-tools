# /choose-web-stack

## Mandatory process

1. Load the installed `pest-controller-suit` Core skill and consult its roster before making any routing decision. This is the first instruction, always, no exceptions. Resolve Core through host skill resolver or explicit selected-plugin registry; source work uses the root catalog source roots. Missing Core blocks routing.
2. Resolve selected web-stack-selection-stinger from web-development-tools for this workflow. Read its guide map. Confirm unresolved public content/search/freshness, interaction/rendering, backend, team, native reuse and hosting constraints. A staging draft is not a registered role.
3. Dispatch web-stack-selection-wasp-drone at top level only if its registered role exists and delegation is authorized; arm its paired Stinger and exact scope. Otherwise read the paired agent and execute directly, truthfully reporting direct use.
4. Compare React19/Vite, SvelteKit, React/Next.js and Vue/Nuxt against the same product. Use fresh official capability/version/deployment evidence. Separate UI framework, build tool and backend language/runtime. No popularity/performance/SEO/native-reuse guarantees.
5. Resolve actual selected implementation, backend, design/components/licenses, infrastructure and review owners. React UI expertise does not prove complete Next server ownership. A security auditor cannot substitute for a missing implementation owner; disclose that gap explicitly.
6. Deliver ONE framework recommendation/status, source-backed fit, route/backend boundaries, actual owner graph, deferred dependencies and future acceptance ledger. No scaffolding, dependency installation, application mutation, provider settings, credentials, spend, deployment, publication or commits occur through this advisory workflow.
