# Qualification examples

These are hypothetical exercises, not execution claims.

## Happy path

Accepted SvelteKit/Neon/WorkOS/Stripe test-only scope yields one workspace onboarding and paid feature. Duplicate payment events leave one durable entitlement transition; another tenant cannot read its records.

## Missing owner

A React/Vite UI owner exists but no selected Stripe backend adapter covers the chosen service: prepare UI contracts and report billing integration blocked; never assign SvelteKit snippets to that backend.

## Failure path

Checkout succeeds but webhook provisioning fails: the return page remains pending, reconciliation is tested, and the foundation is PARTIAL until entitlement behavior passes.
