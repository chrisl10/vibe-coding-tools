# Intake and classify

1. Ask for currency, period, attempted billing unit, successful transaction assumptions, known price, volume, service cost and fixed overhead. Group missing inputs into one question. Never choose a new price here.
2. Record evidence and observation date for each assumption in the worksheet. Distinguish user-provided actuals, official vendor rates, and fictional scenarios. Vendor rates need method, region and contractual scope, not just a homepage headline.
3. Split each cost by behavior and accounting classification using [the field contract](../references/model.md). Fixed/variable and cost-of-revenue/operating are separate axes. Ask when treatment is unclear, or show explicitly labeled alternatives instead of quietly deciding policy. Basis: SBA, American Express.
4. Ask how failed payments affect fulfillment. The bundled model charges service costs on attempted units and assumes one successful transaction each. Use that only if it fits. Ask how refunds and processing-fee returns actually work. Basis: Stripe.
5. Mark unknown costs and evidence gaps. Do not turn missing values into zero. An explicit zero is allowed only with the user's stated rationale.
6. Read the [model and scenario guide](02-model-and-review.md). If the user has mixed products, partial refunds, tiered infrastructure, acquisition payback or late collections, retain an explicit worksheet extension and disclose which calculator result cannot cover it.
