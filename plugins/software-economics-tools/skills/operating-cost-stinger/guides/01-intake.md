# Collect the workload and invoice semantics

1. Ask for the application workload, selected providers, currency and monthly horizon. Architecture selection belongs to platform owners; this task prices the user's supplied configuration.
2. Collect meter quantities for low/base/high: active compute time and size, storage, transfer/egress, requests, jobs, observability retention, auth usage, support tools and any other selected dependency. User count alone is not a billed metric. Basis: [Neon](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/software-economics-tools/skills/operating-cost-stinger/references/research/raw/neon-plans.txt), [AWS](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/software-economics-tools/skills/operating-cost-stinger/references/research/raw/aws-calculator.txt).
3. For each dated rate record region, plan, billable unit, source/contract and whether it is an assumption, current quote or actual invoice. Do not copy the fictional examples into a live estimate. Resolve selected platform specialists through Core to confirm missing constraints.
4. Identify whether a plan is an additive subscription or minimum usage floor. Confirm unit allowances versus money credits and their actual ordering. Basis: [Railway](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/software-economics-tools/skills/operating-cost-stinger/references/research/raw/railway-plans.txt), [Vercel](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/software-economics-tools/skills/operating-cost-stinger/references/research/raw/vercel-pricing.txt).
5. Record shared credit eligibility, scope, available budget and each allocation. A shared organization credit is not duplicated per project. Basis: [Supabase](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/software-economics-tools/skills/operating-cost-stinger/references/research/raw/supabase-invoice.txt).
6. Collect paid operator hours/rate separately from unpaid hours/time value. Missing costs or rates remain gaps; ask before converting them to zero. Read [the model](../references/model.md) before calculation.
