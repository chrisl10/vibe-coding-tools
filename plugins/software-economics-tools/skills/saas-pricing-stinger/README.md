# SaaS pricing

Prepare one provisional commercial price/model recommendation with cost feasibility, dated buyer/substitute evidence, counterevidence and test thresholds. Read [intake](guides/01-intake-and-recommend.md), [experiment](guides/02-test-and-review.md), [model selection](references/model-selection.md), [worksheet](references/templates/pricing-worksheet.md) and [worked cases](examples/pricing-cases.md). [Primary research](references/research/distillation.md) defines model terms and limits.

This component reuses selected Unit Economics, Operating Cost and Competitive Research; it ships no duplicate economic calculator. Runtime creates local advisory artifacts and an unexecuted research proposal. It does not mutate billing, publish prices or contact buyers.

For supplied price comparisons, read [measurement](guides/03-measure-price-results.md), [worksheet](references/templates/price-measurement-worksheet.md), dated primary digest and [fictional arithmetic/cases](examples/price-measurement-cases.md). PostHog owns accepted instrumentation; pricing advisory compares evidence without activating flags or changing bills.

For O281 use [propose fair service limits](guides/04-propose-fair-service-limits.md) with selected Unit Economics. Record buyer value, limits/overflow/recovery, owner-selected fairness criteria and the exact decision in one joined worksheet; costs alone cannot prove fairness.
