# Offline supplied-input calculator

Run `python3 scripts/quote.py input.json` relative to this skill. Input shape and formulas: [model](../references/model.md). The test fixture in [test_quote.py](test_quote.py) supplies an executable website example; app and maintenance cases are exercised in tests. Run `python3 scripts/test_quote.py` after calculator changes. JSON input is bounded to 100000 characters; duplicate keys, nonfinite/extreme numeric values, booleans, missing fields and unsupported periods fail with `quote error:` and exit 2. Valid output is JSON only, without file/network writes. Project and monthly totals are independent; the script does not aggregate different units or calculate business break-even. Two-decimal currency display is a stated convention, not legal currency formatting advice.
