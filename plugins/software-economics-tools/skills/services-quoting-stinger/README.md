# Services quoting

Prepare website, app/integration and maintenance quotations from scoped acceptance and supplied cost evidence. Read [scope and quote](guides/01-scope-and-quote.md), [maintenance/change](guides/02-maintenance-and-change.md), [model](references/model.md), [templates](references/templates/quote.md), and [examples](examples/quotes.md). [Research](references/research/distillation.md) preserves primary-source limits. The optional offline calculator uses supplied amounts; no benchmark rates or purchases. Resolve Estimation and Unit Economics through trusted Core rather than reading cached siblings.

For an agency statement-of-work proposal, use [the SOW guide](guides/03-statement-of-work.md), [worksheet](references/templates/statement-of-work.md), [completed fictional proposal](examples/statement-of-work.md) and dated source digest. Reuse existing scope, quote, maintenance and change records. Legal terms and actual acceptance remain separate owner/counsel decisions.
