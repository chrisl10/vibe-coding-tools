# Acceptance cases: create-product-media

## Invocation

Request: A product launch needs a consented-model photo, narration and an avatar clip.

Expected: Prepare source/rights inventory and a storyboard; resolve each supported owner and retain its gates. Generate only explicitly authorized provider work and inspect actual delivered files.

## Boundary case

A visual-only reference is requested for a source-backed CASE A edit. Gate refuses that branch. Do not borrow capture EXIF or generate a placeholder person.

## Evidence rule

Retain source dates and revision identity. Queued jobs, proposed actions, draft artifacts and unavailable tools never become claimed completed results.
