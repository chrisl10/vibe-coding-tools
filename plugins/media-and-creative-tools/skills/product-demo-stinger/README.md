# Product Demo

Prepare one evidence-bound product demonstration or tutorial: claim worksheet, scenes, narration/caption text, failure coverage and a production handoff. Start with [SKILL.md](SKILL.md).

| Work | Guide |
| --- | --- |
| Match claims to real source and observed behavior | [Prove the story](guides/01-prove-the-story.md) |
| Write scenes and reproducible teaching steps | [Plan scenes and tutorial](guides/02-plan-scenes-and-tutorial.md) |
| Review evidence and hand production to selected owners | [Review and handoff](guides/03-review-and-handoff.md) |

The [worksheet](references/claim-to-scene-worksheet.md) and [fictional example](references/fictional-storyboard.md) preserve absent proof rather than invent it. [Twelve cases](references/negative-cases.json) are unexecuted review scenarios. The [research digest](references/research/distilled-product-demo.md) has six fresh official captures and four repository snapshots. Documentation publication dates are older or unspecified.

Research-only procedure: returns draft/report text for an authorized orchestrator to save. Actual recording is webapp-capture-stinger in browser-and-app-testing-tools; voice and avatar jobs use the selected ElevenLabs/HeyGen owners. Dependencies are conditional: planning needs Core and this pack; recording also needs its actual selected capture owner and tools. No production pack is activated by linking its name.
