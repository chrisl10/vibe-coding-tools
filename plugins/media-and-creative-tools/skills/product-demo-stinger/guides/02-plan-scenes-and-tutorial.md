# Plan scenes and tutorial

1. Create a scene list from qualified claims. Record scene ID, claim IDs, starting state, named control, intended action, visible outcome, narration, disclosure, evidence locator and production status. Planned timings are estimates until measured against final media.
2. Show the goal and starting context first. Follow with one path to success and the most consequential failure or limitation for that goal. A tutorial must also give reproducible prerequisites, permitted actions, expected result and a recovery path. Do not imply recovery was observed unless its evidence exists.
3. Name the focused control and what changes after activation. Narrate essential visible information without relying on color, a silent cursor or “click here.” Prepare synchronized captions for speech, speaker changes and meaningful sound. Arrange captions so they leave focused controls, outcomes and errors legible. These are content review tasks; player accessibility needs separate checks.
4. Label synthetic data, a mocked dependency, intended feature, skipped setup or edited waiting time where it changes the viewer's interpretation. Preserve measured raw duration and edited duration if time is cut; never convert a sped-up clip into a product performance claim.
5. Use the capture owner's current plan schema only after that owner is selected. Keep planning output `approval_status: NOT_REQUESTED` and non-executable by default. Do not set its `approved` flag from this worksheet. Capture owner must obtain the actual approved scene/request scope. Ordinary capture remains read-only; interactive demo approval must name exact local/seeded mutations. Human login and capture masking belong to that owner.
6. Return storyboard, narration, tutorial steps, caption text, omission list and the production handoff. Do not invent a transcript from an unavailable recording. If real evidence is absent, use `references/fictional-storyboard.md` as a formatting example with every scene marked FICTIONAL_NOT_RECORDED.

Grounding: captions, audio description, WebVTT, capture demo contract. Scene structure and disclosure policy are local editorial choices; no universal duration or speaking-rate guarantee is asserted.
