# Product planning research distillation

Fetched and re-read 2026-10-12. The sweep targeted the six months before that date (2026-04-12 to 2026-10-12). Few primary sources on these methods were published inside the window, because the core ideas (Definition of Done, Shape Up, story mapping, topological ordering) are settled. Where that is true, the current official page was re-read and its age is stated, rather than treating age as proof it is stale. Thin or secondary sourcing is marked as such.

## Wasp Nest conventions (not claims from the sources)

These come from the locked topic and existing repository files, not from external research:

- Artifact paths: `library/requirements/plans/wave-plan.md`, `library/requirements/plans/prd-map.md`, `library/requirements/plans/handoff-packet.md`, and `library/knowledge/private/standards/definition-of-done.md`. Library Schema v2 (`src/skills/library-stinger/templates/documentation-framework.md`) does not yet list `requirements/plans/` or `knowledge/private/standards/`; the Library owner must accept these homes.
- Owner approval of each artifact before handoff, and the security-then-quality gate order, come from the Wasp Nest Ship Gate and `/smoke-it` close-out (`src/commands/smoke-it.md`).
- Contract boundaries are only flagged here. `contract-writing-stinger` decides and drafts `CTR` records; `library-stinger` writes PRDs and pins revisions (`src/skills/contract-writing-stinger/guides/01-identify-boundaries.md`, `03-handoff-to-library.md`).
- Acceptance criteria format: the PRD template uses an ID table with Given/When/Then (`src/skills/library-stinger/templates/prd-template.md`), while Library guide 03 shows checkboxes (`src/skills/library-stinger/guides/03-feature-prd.md`). This Stinger follows the PRD template and tells Library so in the Handoff Packet.
- The existing agile-scrum DoD templates (`packs/business-and-product-tools/skills/agile-scrum-stinger/guides/04-definition-of-done.md`) are team and sprint scoped. This Stinger's DoD is project scoped and bound to the Ship Gate; it reuses their maturity idea (startup items first) without copying sprint ceremony.
