# Select controls at named boundaries

1. For an actual VM/network topology, evaluate a provider network firewall/security group for required protocol/source/destination reachability. Evaluate an OS firewall separately only with a selected OS owner and exact evidence. Provider network layers are not interchangeable: AWS security groups are stateful; NACLs are stateless and ordered. Record unavailable egress filtering rather than claiming total isolation.
2. Evaluate a WAF for the supplied public HTTP boundary. Record actual product attachment, request visibility, TLS termination, inspected routes/body restrictions, rule order/action and current plan eligibility. For raw TCP/UDP or protocols outside researched scope, state the coverage gap. Do not label HTTP WAF coverage as protection of database/admin/non-HTTP paths.
3. Evaluate edge rate mitigation for traffic abuse, then application admission for costly/authenticated operations. Describe anonymous IP/proxy grouping separately from authenticated tenant/user/API principal, operation and weighted cost. Verify identity before relying on it; do not use caller-supplied tenant IDs or headers as authority. A WAF or rate bucket does not authorize data access.
4. Verify the proxy chain and whether the last trusted hop overwrites headers. Keep IP attribution UNKNOWN until alternate paths and variable hop counts are reviewed. Cloudflare Worker/IPv6 semantics and shared source ranges matter. A Cloudflare allowlist alone does not prove requests belong to your zone; require the selected owner to assess origin authentication and alternate ingress.
5. For operators/private services, resolve Tailscale if selected and applicable. Inspect policy, devices, identities, approved routes and actual non-tailnet paths. Do not propose a literal ACL/grant edit here or infer that installation implies least privilege.
6. Return ONE layered recommendation conditioned on actual topology. Each selected layer names the threat/purpose, exact placement, principal, provider limits, responsible implementation owner and missing proof. Remove layers with no justified boundary rather than stacking products for appearance.

Grounding: stateful, stateless, AWS aggregation, Cloudflare rate limits/plan, proxy trust, headers, origin, tailnet policy. Application identity, cost admission and owner routing are derived design requirements; they are not implemented by this pair.
