# Prepare mobile distribution

1. Confirm iOS/Android targets, store/private route, account type, seller owner, device capabilities, offline data, backend and money model. A browser prototype does not establish device readiness.
2. For Apple, record individual/organization enrollment prerequisites, authority and membership evidence. For Google Play, record account type, identity/device verification and applicable testing requirements. Route exact current submission/age/privacy/payment policy details to selected App Store Submission; do not infer completion from signup.
3. Inventory app name/icon, screenshots, privacy/data inventory, support URL/contact, bundle/package identity, signing custodian and physical test-device coverage. Add push/deep-link/provider assets only when a feature needs them.
4. Distinguish remote DB/backend preparation from on-device storage requirements. Device encryption/schema migration/offline behavior belong to implementation/testing owners, with evidence requested for the release milestone.
5. Record sourced registration amounts and units where applicable, current regional caveats, renewal and unknown approval timing. Prepare the ledger and blockers. Account purchase, identity entry, signing, submission and release need separate explicit authority.
