## Related owners and host support

Resolve Core Pest Controller, Library, Knowledge and contracts through the trusted catalog/selected registry. Resolve optional Builder Readiness, Infrastructure Fit, Operating Cost, Auth/WorkOS, Payments, App Store Submission, Tauri/Electron, Sentry, Doppler, Tailscale and DB specialists only when selected and required. Do not use relative cached sibling paths or infer that naming a provider installs its specialist.

The `prepare-assets` command routes through selected infrastructure-decision-tools plus Core. Missing optional implementation capability produces a handoff gap, not a guessed setup procedure. When registered delegation is unavailable, read the paired Drone and run this Stinger directly, reporting direct use. Parent-generated Claude/Cowork, Cursor and Codex surfaces remain packaging intentions until built and qualified.

Runtime is research-only. Parent Security then Quality reviews the source forge; static ledger checks do not certify real accounts, owner approval, publication readiness or native host execution.
