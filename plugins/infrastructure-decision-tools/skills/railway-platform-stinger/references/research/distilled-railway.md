## Cost interpretation
For ordinary full-cycle Hobby/Pro included usage, model one workspace charge as `max(subscription floor, aggregate eligible usage)`. Do not subtract the included amount and then apply the same floor a second time. Do not create one included budget per service. Dedicated prepaid/promotional credits require actual scope and ordering evidence; the ledger supplies no transferable unlimited credit pool. Cost totals belong to the selected Operating Cost owner and its supported model. Rates must be refreshed for a real estimate; no production rate is embedded as a calculator default.

## Unknowns and conflicting shorthand
Plans prose describes base plus usage, while its examples specify only the excess above included usage. Prefer the examples and explicit Included usage section for the full-cycle interpretation. The volume page distinguishes default size from expansion eligibility; do not treat Pro's default 50GB as a maximum or its possible 1TB as already allocated storage. No source proves a supplied native binary, kernel privilege, workload latency, external recovery target or production SLA. Region and plan lists can drift.
