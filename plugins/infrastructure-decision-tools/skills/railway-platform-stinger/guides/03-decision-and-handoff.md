# Decide, record responsibilities and hand off
Use the [worksheet](../references/templates/fit-worksheet.md), [case](../references/examples/fictional-case.md) and [negative cases](../references/examples/negative-cases.md).

1. State one Railway recommendation or provisional choice, then the supplied facts that make it fit. Explicitly name rejected/unresolved requirements; do not approve a platform solely because it deploys a container.
2. Draw the service/DB/storage/network boundary in words. Private DNS is within one project environment; external DB connectivity, public exposure and access control need their own proof. Network evidence
3. Name operators for application patching, build/image pinning, secrets, monitoring, incident response, backup consistency, restore/export drills and billing. Railway's service logs/metrics do not prove alert coverage. Image rollback retention is plan-bound and does not restore mutable data. Services, plans
4. Record supplied RPO/RTO and compare with a proposed tested restore/export approach. Backups restore within the same project/environment; an independent disaster copy and database consistency remain obligations. Region migration and volume redeployment downtime must fit the recovery/maintenance budget. Backups, regions, volumes
5. Define reassessment triggers from actual budget, measured resource/queue growth, data size, required geography, recovery promise and operator capacity. Do not invent numeric acceptance thresholds.
6. Resolve selected Infrastructure Fit for topology decisions, Operating Cost for arithmetic, Network Boundaries for exposure design, DB/security owners for their reviews, and an implementation owner for actual deployment. A Railway provisioning owner is not established by this skill: report that exact gap if the selected catalog has no suitable authorized owner. Do not substitute Vercel or generic cloud deployment procedures.

Deliver a local report at `library/requirements/reports/railway/<date>-<topic>.md`, or the agreed local destination when Library is absent. Read-only agent returns the report text to its caller; the authorized caller saves it. Selection grants no account, install, credentials, paid-resource, configuration, deployment or publication authority.
