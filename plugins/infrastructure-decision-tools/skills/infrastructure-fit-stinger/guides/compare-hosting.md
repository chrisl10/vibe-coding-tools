# Compare managed hosting and VPS

1. Use one normalized worksheet. Screen each selected track against runtime, lifecycle, data/region/security and recovery constraints before ranking convenience or price.
2. Distinguish managed functions/static/app containers from customer-operated VMs. Qualify exact plan/runtime/region docs; an overview alone is insufficient for a required numerical limit.
3. Assign operating responsibility from the reference table: application/auth remain yours, and a VM adds host duties. Ask who will patch, observe, restore and handle incidents. No assumed AI on-call owner.
4. Retain a small eligible comparison, not every vendor. Use current AWS Fargate, GCP Cloud Run, DigitalOcean App/Droplet, Railway, Vercel or Cloudflare sources as applicable. Missing Vultr evidence keeps it unqualified/unpriced instead of guessed.
5. Recommend one topology with the decisive discriminator and facts that would change it. If a hard constraint is unknown, mark the recommendation provisional or blocked. Do not provision the selected service.

Grounding: Fargate, Cloud Run, App Platform, Droplets, Vercel, Workers.
