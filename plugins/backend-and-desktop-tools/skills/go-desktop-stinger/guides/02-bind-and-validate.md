# Bind a narrow Go desktop facade

DERIVED procedure. [Wails method binding](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/go-desktop-stinger/references/research/raw/wails-development-source.md) exports public methods of bound instances. [Generated models](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/go-desktop-stinger/references/research/raw/wails-architecture-source.md) provide typing, not business authorization.

1. Design one dedicated facade for required desktop operations and an explicit inventory of every public method. Keep startup/shutdown/helpers unexported; avoid binding whole database, filesystem, shell or admin service objects. An accidental exported helper is an authority change requiring review.
2. Define stable DTOs with explicit json tags and bounded strings, records, enums and numeric representation. Validate again inside Go before opening files, mutating state or calling a provider. Reject unsupported format/version, malformed IDs, paths, links and excessive payloads. Frontend types, dialog filters and deserialization success are insufficient validation.
3. Establish the actual caller model. For a single-user offline app it may be the OS user with explicit operation selections; authenticated multi-user/tenant apps need their accepted auth contract. Neither bundled assets nor an event name grants authority. Keep credentials/backend administrator secrets out of generated models, embedded frontend assets, logs and ErrorFormatter results.
4. Implement services behind the facade under the accepted contract. Use stable public error categories and safe ErrorFormatter mapping when supported by the actual graph; never echo paths, SQL, tokens or provider bodies. Test malformed requests and unexpected exported methods.
5. Prefer bundled reviewed assets. Do not add wildcard remote binding origins or load arbitrary remote content. Review actual origin options and WebView navigation/window/shell-open policy for the resolved graph, and configure/test the supported restrictive CSP delivery mechanism. If required enforcement is unavailable, report a blocked security boundary. The digest does not promise a portable capability ACL. [Options](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/go-desktop-stinger/references/research/raw/wails-options-source.md).
6. Keep dynamic handlers absent unless required. A handler must validate path/type/size and approved roots, deny traversal/link escapes, authorize mutations and bound request/response bodies. Never copy the unrestricted os.ReadFile sample. Treat any custom local HTTP listener as an additional authenticated/authorized surface; localhost is not proof of trust. [Assets](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/go-desktop-stinger/references/research/raw/wails-assets-source.md).
7. Invoke native file dialogs through purpose-specific Go methods with runtime readiness. Empty/nil selection means cancellation, no operation. Bind selection to a bounded operation; normalize with target-native semantics, retain verified handles where supported, and require separate approval for overwrite/deletion/upload. No arbitrary renderer filesystem or shell entry point. [Dialog](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/go-desktop-stinger/references/research/raw/wails-dialog-source.md).
8. Regenerate bindings through the exact installed tool and inspect their diff together with Go signatures; run frontend typechecks and request/response contract tests. Wails events are notifications with validated names/payloads, job correlation, bounds and listener cleanup. They do not supply documented authorization, ordering or backpressure guarantees. [Events](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/go-desktop-stinger/references/research/raw/wails-events-source.md).
