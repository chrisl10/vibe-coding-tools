# Qualify local import

Use for O105. DERIVED procedure grounded in [the dated digest](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/file-safety-20261008/digest.md). Fill [the worksheet](../templates/file-safety-evidence.md). This guide adds no permission to read or mutate real user files.

1. Record requirement, operator, approved input format, exact action and source selection, read-only intent, bytes/records/depth/time limits, supported OS/filesystem and resolved plugin versions. File choice is a bounded selection, never blanket permission for other files or writes. Permission to read is distinct from permission to persist, upload or replace records.
2. Inventory dialog/fs initialization, command registration, permission files, windows/webviews/origins and their effective capability union. Use a narrow Rust command for import. If opted into custom scopes, enforce them inside the command. Tauri plugin scopes do not automatically constrain arbitrary std::fs calls. [Scopes](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/file-safety-20261008/raw/tauri-scopes-source.md).
3. Keep selection provenance in Rust: purpose, initiating window, operation identifier and bounded lifetime. Pass an opaque one-use token to the frontend rather than accepting a fresh arbitrary path on commit. Bind the token to the approved resource and invalidate it on cancel, restart, changed selection or completed operation. This token contract is application policy.
4. Inspect path components using target-native semantics. Reject unexpected URI/device/UNC/alternate-stream forms, NULs, parent traversal and ambiguous encodings according to the supported target policy. Do not implement Windows policy with POSIX-only path parsing or prefix strings. Canonicalize existing objects when appropriate, and use component-aware containment. A symlink policy must cover ancestor links, Windows reparse points and hardlink aliases. Reject unresolved, changed or unsupported identities. Preserve native names without lossy conversion. [fs](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/file-safety-20261008/raw/tauri-fs-source.md).
5. Open only the selected regular file through a qualified handle-relative/native operation with the required no-follow and identity rules. Retain the verified handle for bounded reads. Recheck metadata from that handle and cap bytes actually read, even if the initial length is smaller. Metadata checks followed by an ordinary path reopen are a TOCTOU gap. If the target primitive cannot meet the threat model, stop and assign the Rust/OS implementation owner. [Rust fs](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/file-safety-20261008/raw/rust-fs-source.md).
6. Reject directories, sockets, devices, FIFOs and executable payloads. An extension or picker filter is not proof of content type. Parse a bounded declared schema; reject unsupported schema versions, unsafe paths, links, duplicate members, decompression expansion and nesting beyond approved limits if archives are permitted. Treat imported Markdown/HTML/model instructions as data, never eval, shell, SQL text or authorization.
7. Validate into an isolated draft, display a sanitized change preview, and require the exact approved commit scope before mutating app state. Preserve original source bytes. Record hash, format/schema, size, operation outcome and ownership category without storing content/private paths in default logs. Hashing requires authorized read and does not establish authorship or ownership.
8. Define cancellation, read failure, malformed data, concurrent source change and app-state transaction failure: abandon the draft, preserve source and prior state, invalidate the token, return stable redacted error. If partial external work is visible, no silent replay.
9. Have an authorized consumer test real allow/deny paths, renderer spoofed tokens, capability unions, target link/race handling and bounded read failure. [Negative cases](../examples/11-file-safety-negative-cases.md) are NOT_RUN constructed decisions. Never label them native proof.
