# Qualify Linux distribution fit

Use for O101. Read [the dated digest](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/distilled-native-release.md). This is a DERIVED procedure; refresh package and distribution documentation at release time.

1. Collect supported distributions and versions, architectures, desktop/session requirements, tray/graphics features, libc baseline, package-manager expectations, offline installation and update ownership. Recommend the target's native package first when users expect package-manager lifecycle; use AppImage when portable file delivery fits the audience and its runtime constraints have been tested. Do not select a distribution format solely because the bundler emits it.
2. Establish one support row per distribution/version/architecture/package route. Build on the oldest supported baseline that supplies the required WebKitGTK 4.1 dependencies. A newer build can increase the glibc requirement. Ubuntu 22.04/Debian 12 are documented baseline examples, not a promise that every build supports them. [Tauri AppImage](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/raw/tauri-appimage-source.md).
3. For DEB, inspect generated control metadata and contents with available `dpkg-deb --info /path/to/App.deb` and `dpkg-deb --contents /path/to/App.deb`. Confirm target repositories satisfy GTK/WebKitGTK, tray and any application-specific dependencies. Record package architecture and required versions. [Tauri Debian](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/raw/tauri-debian-source.md).
4. For RPM, use available `rpm -qip /path/to/App.rpm`, `rpm -qp --requires /path/to/App.rpm`, `rpm -qpl /path/to/App.rpm`, and `rpm --checksig /path/to/App.rpm`. Report missing trusted keys separately from corrupt artifacts. Repository/package signature trust and Tauri updater signatures are distinct. [Tauri RPM](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/raw/tauri-rpm-source.md).
5. For AppImage, record architecture, build baseline, executable delivery permissions, host runtime/mount requirements and graphics/WebKit behavior. AppImage bundles many dependencies but does not imply every kernel, libc, GPU or desktop environment works. Inspect candidate dependencies in an isolated qualified environment; do not execute an untrusted artifact or run `ldd` on arbitrary untrusted binaries as part of a documentation audit. [AppImage](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/raw/appimage-concepts-source.md), [Tauri](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/raw/tauri-appimage-source.md).
6. Have the release owner test installation and first launch on the actual minimum-supported and representative current targets, offline dependency availability, WebKit rendering, sidecars, tray, updates and removal. A container build is build evidence; it does not prove a desktop session or a real device works.
7. Decide who owns updates. Do not combine repository-managed upgrades and a self-updater without an explicit ownership contract. Document installed file permissions, rollback/reinstall path and persistence/schema compatibility. No automatic downgrade guarantee follows from Tauri's updater primitives. [Tauri updater](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/backend-and-desktop-tools/skills/tauri-stinger/references/research/native-release-20261007/raw/tauri-updater-source.md).
8. Fill [the qualification template](../templates/native-release-qualification.md). Mark unavailable targets OPEN. Package uploads, repository keys, signing and installer execution require their own authority.
