# Qualification examples

These are hypothetical exercises, not execution claims.

## Happy path

An offline field-notes tool with an existing Svelte UI and bounded filesystem access selects Tauri/Rust, pins a note-store IPC contract, and requires packaged native verification on the actual target OS.

## Missing owner

The required desktop capability has no verified selected plugin/implementer: return a provisional shell choice and the specific missing owner rather than promising compatibility.

## Failure path

The UI browser test passes but packaged OS behavior is untested: report only browser evidence, keep native/distribution qualification open and require the named native spike.
