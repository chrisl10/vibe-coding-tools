# Qualification examples

These are hypothetical exercises, not execution claims.

## Happy path

A team with existing Python libraries and conventional business CRUD receives a Django/Ninja recommendation with python-wasp-drone implementation, separate database/auth owners and a scoped integration spike.

## Missing owner

Go is feasible but its selected pair documents module/build work only: report the broader backend architecture ownership gap and keep the recommendation provisional.

## Failure path

A required library cannot support the target runtime: exclude that candidate with current official evidence and do not silently replace the user-named integration.
