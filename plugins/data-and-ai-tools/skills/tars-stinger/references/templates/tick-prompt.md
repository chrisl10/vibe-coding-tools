# 10-minute tick prompt

Register with `CronCreate` cron `*/10 * * * *`, recurring. Paste the prompt below with the state folder filled in. Note the returned id in the ledger. The tick fires only while TARS is idle, so TARS ends its turns promptly.

```text
TARS tick. State folder: <path>. Load tars-stinger guides/03-ten-minute-tick.md and run it now: read notifications, check each managed session's real transcript, act on stalls, run the CI watchdog, append one ledger line, then go idle. Do no implementation work.
```
