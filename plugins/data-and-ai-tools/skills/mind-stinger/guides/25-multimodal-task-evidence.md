## Write the task contract before scores

1. State the user outcome: extract chart values, transcribe meeting decisions, locate a video event or answer from a screenshot. Define allowed inference, expected source evidence, units, timestamps, tolerance, abstention and prohibited claims/effects. A fluent summary is not success unless it fulfills the task.
2. Inventory only authorized test media. Record media hash/version, source, rights/consent scope, dimensions/duration, encoding, language and permitted retention. Track OCR/transcript/frame/crop/summary hashes with transformations and original coordinates/time offsets. The derived text is a lossy artifact, never a substitute for source evidence.
3. Version the test set, labels, split, preprocessing, provider/model, prompt, configuration and scoring code. Keep train/tuning examples separate from held-out cases; group near-duplicate media to prevent leakage. Freeze a released set; add a version rather than editing history. Missing actual media means review-only coverage.
4. Cover deployment slices: noisy audio, accents/languages, overlap, silence, small/blurry/rotated text, dense charts, occlusion, long duration, relevant event between sampled frames, conflicting modalities, unsupported formats and embedded malicious instructions. Select actual slice distribution from the product's user tasks. Record gaps instead of inventing universal percentages.
5. Use human ground truth appropriate to the task: source-aligned timestamps for video, verified chart cells/units, transcription labels and speaker boundaries when speaker identity is permitted. Provide label disagreement/adjudication and uncertainty. Do not infer a person's identity, emotion or medical status from ambiguous media when the task lacks valid evidence.
6. Score task correctness, omissions, unsupported claims, citation/coordinate/time accuracy, abstention, prohibited effects, latency and observed cost separately. Report denominators per slice and severity of failures. An average can hide one dangerous error. Calibrate any LLM judge against human labels; the evaluated model judging itself is not independent proof.
7. Check pipeline stages before blaming the final prompt: upload parser, OCR/STT, frame coverage, offset mapping, source access, retrieval selection, answer assembly. Verify whether relevant evidence ever reached the model. Repeat tests only after a material change and record what changed.

## Evidence gate

Fill [the task worksheet](../templates/multimodal-task-review.md). Retain actual input/derived artifacts, model output and human expected result under approved access, with artifact hashes in a metadata-only report. Compare prior and candidate using the same held-out version and documented nondeterministic repetitions. Predetermine acceptance and severe-failure handling with the owner; never retrofit thresholds after seeing scores.

Rendered cases in this skill are hypothetical design reviews and require actual media/task execution before closure. JSON/schema checks prove format, OCR text comparison proves a stage, and a synthetic label table proves neither model perception nor live media quality. Quality receives the full task evidence, Security receives authority/injection findings. Do not claim accessibility, legal consent, model accuracy or production readiness from this packet alone.
