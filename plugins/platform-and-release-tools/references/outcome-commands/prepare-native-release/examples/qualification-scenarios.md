# Semantic qualification scenarios

| Trigger | Required behavior |
|---|---|
| Tauri updater signature exists | Still require OS-signing and final installer evidence as separate rows. |
| browser-only smoke passes | Native packaged/device criterion remains unproven. |
| certificate account absent | Record owner action without creating account or entering credentials. |
| iOS package produced | Do not imply store upload or physical-device acceptance. |

These scenarios qualify procedure semantics only. They do not claim live harness execution or application behavior.
