# Qualification examples

These are hypothetical exercises, not execution claims.

## Happy path

An existing SvelteKit/WorkOS/Neon repository has authorization to edit the local tenant guard. Auth/WorkOS and DB owners pin tenant claims, the framework owner implements the guard, and cross-tenant/removed-member checks feed Security then Quality.

## Missing owner

data-and-ai-tools is not selected: identity/secrets inventory can proceed, but schema/tenant persistence implementation remains blocked on db-wasp-drone.

## Failure path

A preview environment unexpectedly uses production secret-name mapping: preserve the finding, prepare the source correction, and leave live provider sync closed until separately authorized.
