# Semantic qualification scenarios

| Trigger | Required behavior |
|---|---|
| non-Node native runtime | Resolve qualified platform owner; do not assert DevOps implements language build. |
| old green SHA | Invalidate candidate qualification until exact final revision proof exists. |
| rollback target live production | Prepare drill, stop execution pending specific authorization. |
| migration lacks reversible data plan | Flag compatibility/rollback gap instead of inventing a down migration. |

These scenarios qualify procedure semantics only. They do not claim live harness execution or application behavior.
