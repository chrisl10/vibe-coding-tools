# Grounded Plain-Language Example

The input packet and Markdown use the archived official DigitalGov guide.
The two bounded claims concern clear language and writing for the reader.
They do not promise measured comprehension, a grade formula, legal compliance
or any imaginary product feature. No public publication approval is supplied.

The complete-example folder is an actual local render and review proof.
Its reader folder contains only Markdown, editable DOCX, exported PDF and both
citation lists. Full source/claim records and page review proof stay in _internal.
Do not distribute that internal directory as reader content.
