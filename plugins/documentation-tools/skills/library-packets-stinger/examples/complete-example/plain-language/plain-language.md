# Plain Language

DigitalGov describes plain language as clear and easy to understand. [C01]

## Write for the reader

DigitalGov says public text should fit its reader. [C02]

- Plain language uses clear words. [C01]
- Public content serves its intended reader. [C02]

| Idea | Source principle |
| --- | --- |
| Clear words | Make content easy to understand. [C01] |
| Reader | Write for the intended audience. [C02] |
