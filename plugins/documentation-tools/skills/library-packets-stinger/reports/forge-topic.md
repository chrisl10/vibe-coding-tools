# Library Packets: Forge Topic

Date: October 6, 2026. Source repository: the-wasp-nest-source. Stage 1 complete.

## Domain

Turn any user-selected library folder into evidence-grounded audience document packets. Inventory and read sources, record contradictions and coverage, choose supported document types, write clear audience-specific Markdown, and export the same content to Word and branded PDF with a citation list. Inspect every final page. Never invent missing facts or publish private implementation detail in public documents.

## User requirements

Every selected document has Markdown, editable Word, PDF and a reference citation list. No em dashes, unnecessary information or wordy explanations. General explanations target grade 8; engineering documents retain needed technical precision. Public documents omit internal technical details, jargon, private paths, credentials and otherwise revealing information. Reports use the real Legion Code Inc. icon-plus-word-mark logo in the footer. Intake asks the user the library, audience, purpose, scope, evidence/status, public exclusions, research/date, analogy, branding and output questions that are not already answered.

## Source sufficiency and delivery contract

Enough evidence determines the packet's breadth. No minimum document/page quota. A thin or contradictory library produces a coverage report and specific missing-source requests, not fabricated content. The same accepted source/claim map drives all formats. Public and internal citation projections preserve provenance without leaking private source paths. Final completion requires all requested formats, resolved citations, source/publication review, readable prose, and visual review of every PDF and rendered Word page.

## Forge sequence

Research fresh current primary documentation, archive each body with URL/date/type, write a cited distillation, then references/templates/scripts, procedural guides, and the root skill last. Validate skill/agent/command for each target, inspect a grounded sample packet, independently sample research and privacy boundaries, register, and build portable artifacts. Missing dependencies or missing real logo remain explicit blockers to the dependent output, never a silent substitution.
