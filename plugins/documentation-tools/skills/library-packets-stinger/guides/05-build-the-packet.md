# Build the packet

1. Read [the helper contract](../scripts/README.md). Create the packet JSON from accepted sources, reviewed claims and the audience manuscripts. Source paths resolve inside the agreed library; manuscripts and approved images resolve within their declared roots.
2. Validate before rendering. Fix missing/stale sources, quotes or locations, undefined claim IDs, uncited factual units, inappropriate status changes, prohibited prose and public disclosures. Do not bypass a failed check to obtain attractive output.
3. Choose the approved subject style and real Legion footer. The bundled `assets/legion-footer.png` includes the icon and word mark; the footer names Legion Code Inc. as preparer by default (set `--prepared-by` or `LIBRARY_PACKETS_PREPARED_BY` to rebrand), not owner of an unrelated subject. Preserve aspect ratio. Missing real logo blocks branded export.
4. Render from the same reviewed manuscript to editable DOCX. Use named styles, readable body type, purposeful widths, repeated table headers and deliberate spacing. Set section footer inheritance explicitly. Do not shrink body type or force extra pages to meet a quota.
5. Export that DOCX with an existing approved renderer to PDF. The supplied helper uses available LibreOffice/soffice and a temporary profile. If the host has another native document renderer, use its supported equivalent with the same review contract. Do not install a dependency, send a private file to a cloud converter or silently omit Word/PDF.
6. Save each document's Markdown, Word, PDF, `citations.md` and `citations.json`. Keep the private full ledger and source quotes outside public folders. Build public archives from explicitly approved document folders only.
7. Render page images and record the actual DOCX/PDF identities. Conversion success and extraction parity do not constitute page inspection; follow the next guide.

Word section/style controls are F07-F14; Word content/image APIs are F27; conversion controls are F28. PDF extraction limits are F19-F22. Footer brand identity is supported by F25/F26 plus the user asset provenance. [Distillation](../references/research/distilled-library-packets.md), Word footers, Word styles, Word construction, LibreOffice conversion, [asset provenance](../assets/PROVENANCE.md).
