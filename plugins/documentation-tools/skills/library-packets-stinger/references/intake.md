# Invocation questions

Ask only what the current request and accessible files have not answered. Group related questions into short batches supported by the harness. Preserve answers for this packet; do not ask for the same decision again. A missing answer blocks only dependent work. Sources cannot answer permission questions on the user's behalf.

## First batch

1. **Library and identity:** Which library folder should I read, what product or business does it describe, and who owns it? Is related code available for read-only checks?
2. **Readers and decisions:** Who will read the packet, and what should each reader understand or decide? Choose the full supported packet or name the documents you need.
3. **Product account:** Should these documents describe current behavior, the specified finished product, or both? Which source wins when requirements, contracts and private notes disagree?

## Second batch

4. **Public boundary:** Which documents may be shared publicly? Which features or business facts may appear, and which subjects, prices, names, metrics or implementation details must stay private? May supported private facts use approved public-safe source labels?
5. **Research:** May I use official live pages and published research to fill external gaps? Is Firecrawl/EXA required when available? What comparison date, named competitors and retrieval-date limits apply?
6. **Writing:** What language and voice should I use? Would a consistent analogy help, or should I write directly without one? General explanations target grade 8; engineering documents keep necessary precision.

## Third batch

7. **Brand:** Where are the subject's approved brand assets and examples? The default report footer uses the bundled Legion Code Inc. icon and word mark. Which report style or page size do you prefer, if any?
8. **Scope:** Should I produce the full supported catalogue or focus on named roles and questions? Are there length, time or research-credit limits?
9. **Output:** Where should the new packet be saved? Each selected document receives Markdown, Word, PDF and citations. Should it be a new version or an authorized revision of an existing packet?
10. **Review:** Who can settle source conflicts and public-content questions? Which terms, comparisons, names or topics should be excluded?

## Defaults and boundaries

Use clear English and Letter portrait only when no contrary preference was supplied. Use the real bundled Legion footer, never a made-up logo. Offer all supported document types without a minimum page or document quota. External research requires the user's scope; no paid account creation, new credits, publishing or external messages follow from document creation. Public exclusions, library access and unresolved source authority are required answers when they affect the packet.

Do not request reconfirmation of Markdown/Word/PDF/citation output, the Legion footer, plain language or no em dashes; those are this command's standing output contract. A user may narrow optional content, but missing required formats means the packet remains incomplete.
