## Regeneration and compatibility record

Record exact offline invocation, input/config/template hashes, output location, output digest, expected nondeterminism, second generation diff, compile checks and consumer import checks. Record license/notice files and package content review. A deterministic diff is not runtime compatibility.

For each supported consumer, record old/new client versions, server release or named fixture, request equivalence, response/error behavior, import surface, executed cases, result and missing native evidence. Compare against an independent baseline or approved expectation, not output regenerated by the same candidate.

## Version and close-out

Separate API wire version, SDK package version and generator version. State affected consumers, migration steps, approved deprecation/removal dates, and `[BREAKING]` changes. Do not invent a deadline or alter an Accepted contract. List generation, compile, mock transport, authorized server and native consumer evidence separately. Security then Quality then parent repository-health gates apply before any authorized commit/publish.
