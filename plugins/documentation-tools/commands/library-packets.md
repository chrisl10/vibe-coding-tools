2. Load `../skills/library-packets-stinger/SKILL.md`. Confirm whether the trailing request already supplies library access, subject, readers, decisions, product account, public exclusions, research scope, brand assets and output location. Ask only unresolved questions from `references/intake.md` in short batches.
3. Dispatch `library-packets-wasp-drone` at top level when the harness supports the registered role. Begin the dispatch with: you are library-packets-wasp-drone; read your paired library-packets-stinger in full before doing anything else. Supply the exact source/output scope, user decisions and completion checks. If native roles are unavailable, read the paired agent instructions and execute the same skill workflow directly; do not claim a native agent was launched.
4. Inventory/read the library, map features and claims, and choose only supported documents. Use authorized primary research when needed. Missing sources produce specific questions and deferrals, never invented content or artificial page counts.
5. Produce the approved audience manuscripts, editable Word, branded PDF and citations from one reviewed model. Use the real Legion Code Inc. icon-plus-word-mark footer. Public documents and references exclude technical/private disclosures; full evidence stays in `_internal`.
6. Validate sources, citations, status, grade-8 general prose, public boundaries and output parity. Inspect every final Word-render/PDF page for whitespace, cutoffs, figures, tables, fonts and the actual footer. A successful conversion or a model-written pass does not replace inspection.
7. Deliver the reader index, supported packet, citations and the privately scoped coverage/gap/review record. Report exact completion and missing items. Do not modify source files, implement gaps, publish, message, commit, install dependencies or change settings without the relevant task authority.
