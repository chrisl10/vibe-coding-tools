# Completed report review checklist

A completed draft identifies its purpose, source coverage, acquisition method, evidence register, findings and limitations. Every material block has a tier and evidence coordinates. Estimates are visibly separate. Amounts, dates and descriptions agree across documents.

Check every Word and PDF page after rendering. Record which application/converter was actually used. Keep training fixtures out of case results. The five renderers generate one selected document each; pre-litigation output is a combined draft. There is no fixed page, tab or letter count.

Do not accumulate private case summaries in this public skill. Keep case reports, original records and personal details in the user-authorized private workspace.
