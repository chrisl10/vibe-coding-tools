# Party profile worksheet

Use one private profile per party. This blank template supplies no actual party or allegation.

Record legal name and aliases, role in the agreement, source for corporate identity, authorized contact, relevant contract clauses, billing records and delivered work. Include dates and exact evidence coordinates. Describe related entities only when supported by records; a name, location or shared address alone does not prove ownership or liability.

Keep unknowns, disputes and records requested separate from established facts. Counsel evaluates any legal relationship, service, liability and record request. Do not copy a training fixture into a real profile.
