# Evidence memo for counsel review: authoring checklist

This is a blank writing outline, not executable input or a retained matter. Write only sections supported by this case's records, then encode them under the corresponding document kind in [the renderer schema](../case-facts-schema.json).

## Purpose and scope

Identify reader, review questions, source coverage and missing materials. Do not promise a conclusion before analysis.

## Findings and counterevidence

For each statement, include evidence coordinates, tier, method and limitations. Separate observed records, estimates, testimony and disputed facts. A cited invoice proves the invoice's contents, not automatically payment or delivery.

## Reconciliation and questions

Reconcile amounts and dates. Keep alternative explanations visible. Describe the records still needed and who should review them. Counsel determines legal interpretation, privilege and any external action.

## Sources

List source IDs and exact coordinates. No default party, budget, law, damages figure, page count or outcome is supplied.
