# Plain-language explanations

Target grade eight. Define necessary technical terms in ordinary words. Use one analogy only when it helps, then stay consistent. A work-order checklist can explain a contract, receipts can explain source records, and a calendar can explain observed activity.

Do not use the analogy to imply theft, deception, danger or fault that the evidence has not established. Avoid invented amounts, emotional reassurance, predictions and medical comparisons. Engineering detail belongs in the technical report.
