# Pre-litigation review draft

Ask whether counsel wants findings, a demand, a termination proposal or other sections. Do not select recipients, deadlines, amounts, service methods or legal grounds from a previous matter. Use `templates/pre-litigation-pack/` only as writing checklists.

`build_pre_litigation.js --case-facts FILE --out-dir DIR [--format docx|markdown]` renders one combined `pre_litigation` review document containing the supplied sections. It does not create seven separate letters or convert PDFs. No output is sent.

State facts precisely and preserve disputes and uncertainty. Do not make personal threats, infer intent or pressure a party through unrelated allegations. Counsel determines any rights, preservation request, termination basis, cure period, service method or filing decision under the actual contract and jurisdiction. A header does not create privilege.

Review the complete draft before sharing. Any external send requires the controlling user's explicit authorization for that action. The tool provides no delivery function.
