# Intake

Ask in one compact batch: project and parties; engagement dates; requested questions; available contracts, invoices, receipts, communications, code and logs; who may read the output; actual jurisdiction if counsel review is needed; desired document kinds and authorized output folder.

Create a private workspace chosen by the user. Keep acquired originals separate from working extracts and report drafts. Record each acquired file's hash, provenance and coverage. Avoid copying customer data into this public skill repository.

Working investigation notes can use any reviewed local format. They are not `case-facts.json`. Prepare the renderer input only when a person has reviewed the evidence and written sections. See [contract](10-case-input-contract.md).

No counterparty, budget, law or finding is preselected. The [party profile](../templates/defendant-profile-template.md) is a blank worksheet. Fixtures under `examples/` are invented training records only.
