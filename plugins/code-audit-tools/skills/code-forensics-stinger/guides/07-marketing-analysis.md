# Marketing and account reports

Identify the contracted scope before evaluating outputs. Record the reporting window, metric definition, denominator, platform, audience size and collection method. Compare matching metrics and periods; small samples may not support a trend.

A benchmark is context, not proof of performance failure, authorship or fair value. A low engagement count does not establish AI authorship, missing work or billing misconduct. Inspect actual delivered assets and contractual promises, then preserve counterevidence.

Use current dated primary reports when a comparison matters. Record fees, service mix and assumptions for any value estimate. The public skill contains no default prices or damage multipliers. Put an estimate in a DERIVED block with source IDs and `estimate: true`; keep actual invoices and payments distinct.
