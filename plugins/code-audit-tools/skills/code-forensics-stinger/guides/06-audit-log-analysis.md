# Operational logs

Record the export source, timezone, event schema, retention window and known collection gaps. Preserve the original export. Classify observed actors only when account ownership or other evidence supports the classification.

Separate content edits, configuration, maintenance, automatic jobs and unknown activity. Automated work may satisfy part of a contract; evaluate the actual agreement rather than excluding it by default. Logs record their own observed events, not all work by every party.

Describe gaps as gaps in the captured record. Do not equate a missing event with an unmaintained system or a contractual violation. Cross-check version captures, deployment records, invoices and communications. No log parser is bundled for every product; document any custom extraction method used.
