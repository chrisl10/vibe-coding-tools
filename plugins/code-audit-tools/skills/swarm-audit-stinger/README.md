# swarm-audit-stinger

Answers a broad question about a repository (every branch, the state of the union, where delivery failed, what to do next) with a Workflow fleet of single-lens investigators, adversarial verification, interpreters and a completeness critic, observed every 10 minutes so nothing goes unreviewed. It changes no code.

## When to use

- "Swarm audit this repo", "state of the union", "audit every branch local and remote"

## What it writes

A master report with every fact labelled VERIFIED, REPORTED, or UNVERIFIABLE-HERE, filed under `library/requirements/reports/<domain>/` only with the owner's authorization.
