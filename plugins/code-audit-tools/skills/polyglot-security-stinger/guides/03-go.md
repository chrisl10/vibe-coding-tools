# 03 Go (net/http, Gin, Echo, Fiber)

For every path under stack id `go`. Loads [../references/ecosystems/go.md](../references/ecosystems/go.md) and [../references/cross-cutting/tool-commands.md](../references/cross-cutting/tool-commands.md).

## Steps

1. **Identify the router** from `detect.json.details.go[].frameworks` (gin, echo, fiber, chi, gorilla-mux, or `net/http`). Note the `go` directive version.
2. **Run gosec** in the copy when Go is installed: `go run github.com/securego/gosec/v2/cmd/gosec@v2.29.0 -fmt json -out "$RAW/gosec-<path>.json" ./...`. Its rule ids map to checklist rows G1 to G13 [raw/go--gosec.md]. If Go is not installed, record the cap and continue with `rg`.
3. **Map routes and middleware.** Find route registration (`http.HandleFunc`, `mux.Handle`, `r.GET`, `e.GET`, `app.Get`, route groups) and the auth middleware on each group. Record a route table with auth verdicts in notes.
4. **Run the checklist G1 to G13** with the reference's `rg` blocks; read each gosec and `rg` hit in production code and trace the value.
5. **SQL.** `fmt.Sprintf` or `+` into `Query`, `Exec`, gorm `Raw`, `Where(string)`, `Order(string)` (G1). Dynamic `ORDER BY` from a query string is the usual real case; the fix is an allowlist.
6. **Templates.** `text/template` used for HTML, or `template.HTML(...)` wrapping user data, is XSS (G8) [raw/go--html-template.md].
7. **Binding.** Check that `Bind`, `ShouldBindJSON`, `BodyParser`, or `json.Decode` target request DTOs and not database models with privileged fields (G10). Framework binding defaults are a thin spot in this skill's research: read the struct and the update call, do not assume [research/distilled-polyglot-security.md].
8. **Server setup.** `http.Server` timeouts (G5) and `InsecureSkipVerify` (G6) [raw/go--gosec.md].
9. **CSRF.** If cookie sessions are used, find the CSRF middleware registration or an origin check (G11). Report only what the code shows.
10. **Dependencies.** osv-scanner with call analysis, or govulncheck when `intake.json.execution.allowed` is true (it loads the module; run with `GOTOOLCHAIN=local`); reachability decides severity (guide 10) [raw/deps--govulncheck.md].
11. **Write findings** per guide 14 with `tags: ["go", "<framework>", "<class>"]`, and add the gosec rule id to `refs` when it applies (for example `gosec:G201`).

## Done when

gosec ran or its cap is recorded, every route group has an auth verdict, every checklist item has a result in notes, and every production hit was read.
