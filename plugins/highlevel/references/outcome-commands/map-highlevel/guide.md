Traverse workflow-local `next[]` edges, preserve branch structure, resolve assets using graph linkage, deduplicate touched assets, and retain the identifier map for traceability. Do not flatten branch-scoped order into a false execution sequence.

Keep unresolved jumps, absent triggers and sparse email metadata explicit; a diagram must not imply completeness the export lacks.

If rendering cannot run, report syntax/lint evidence separately and mark rendering unverified rather than installing a renderer silently.
9. Produce `highlevel-map-report.md` listing source hash/date, selected workflows, asset coverage, gaps, output paths, lint/render evidence and freshness limits. This is a one-way export map; it does not update or continuously synchronize the account.
