# Coordination evidence record

Use the selected AppPrimer Zero worker brief and wave handoff for the actual assignments. This record supplements them; it is not another scheduler or schema.

| Evidence layer | Fill with actual evidence |
|---|---|
| Authority | User instruction, task, scope, coordinator delegation, excluded effects |
| Preparation | Current validator path/version/hash, wave input, actual verdict and limitations |
| Selected capability | Host/carrier/version if observed, enabled role resolution, available dispatch/status/stop surfaces |
| Capacity | Numeric limit with source, whether parent is included, all active workers and nested work, remaining slots |
| Settings | Effective observed model/effort/permissions or unknown; inherited defaults; any explicit user override |
| Ownership | Checkout, canonical disjoint prefixes, shared-file owner, runtime symlink/path inspection |
| Contracts | Exact revision/status and actual approval evidence; blocked producers/consumers |
| Supervision | Effective deadline, review times, inspected files/check output, attempts, stall decision |
| Stop/handoff | Stop request and acknowledgment, actual final status, saved paths, child processes, remaining work |
| Integration | Final candidate identity, combined checks, Security then Quality then health, source changes after reviews |

Mark each entry planned, author-asserted, observed or independently checked. Leave unknowns unknown. Idle status alone does not prove all child processes ended. No field approves settings, publication, spend or credential use.
