## Refusal cases to retain

- Unknown workflow key refuses, rather than silently skipping conditional dependencies.
- Owner version differs from Core refuses, even if a file exists.
- Command resolves while its chosen conditional audit branch refuses.
- Empty handler JSON for an unsupported payload cannot be reported as a successful recognized validation.
- Offline hook fixtures do not establish an actual host deadline or stdin transport timeout.
- Source command inventory does not imply native command selector discovery.
- A zero-agent standalone or command-only owner remains valid without fabricated roles.
