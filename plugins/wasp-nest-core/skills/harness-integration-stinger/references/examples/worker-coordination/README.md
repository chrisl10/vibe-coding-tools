## Stopped worker and handoff, illustrative

A documentation worker stops with one saved guide and an unfinished example. The coordinator requests native stop, obtains acknowledgment, inspects final status and known background processes, and preserves the guide's hash, actual checks, attempts and original deadline. Only after confirming the old worker cannot write does the coordinator lease the remaining example to a replacement. Missing stop acknowledgment means the lease stays occupied. The combined candidate still needs ordered review after integration. This is a worked procedure; no stop tool was exercised in this qualification batch.
