# readme-writing-stinger

The procedural arsenal for `readme-writing-wasp-drone`. Encodes the structural rules, badge discipline, OSS/internal distinction, and README-driven development methodology that turn a README into a conversion surface.

The current [Drone identity](../../agents/readme-writing-wasp-drone.md) defines the scope. [Its routing guide](../pest-controller-suit/guides/readme-writing-wasp-drone.md) explains when to use it, and `research/research-summary.md` retains the research provenance.

The foundational constraint: **a visitor makes a go/no-go decision in 30 seconds.** Every guide in this folder derives from that constraint.
