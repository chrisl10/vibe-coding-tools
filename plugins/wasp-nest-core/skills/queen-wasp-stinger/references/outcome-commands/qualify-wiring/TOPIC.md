# O291: Qualify component wiring

Create a Core source composition command, qualify-wiring, for reviewing the actual skill/agent/command/plugin source, generated host projections, selected owner/version/prerequisites and explicit installed-host proof gaps. Queen owns source construction and portability; Harness Integration owns selected/native capability evidence; Security then Quality then parent Health own final review.

This command composes existing validators/build/resolver tools. It adds no validator, installer, registration API, scheduler or automatic trust/activation. Source, projection, selected installation and native execution remain distinct. All four supported harnesses receive self-contained instructions with declared reduced coverage where tools are absent.

Source changes are development-focused and use the existing Ship Gate. Installed mutation, trust, settings, provider effects, commits and publishing require task-specific authorization. O291 remains OPEN until independent gates and generated output qualify this command.
