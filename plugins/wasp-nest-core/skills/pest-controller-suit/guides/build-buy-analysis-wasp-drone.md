Proposed source owner: business-and-product-tools. Core and this selected owner required after parent registration.

Trigger: compare build, buy or partner for one defined feature or product function; compare operational ownership and exit between sourcing approaches.
Inputs: accepted requirements, user job, existing system, volume/data/region, dated supplied costs, common horizon, available approaches, decision owner and operational constraints.
Outputs: requirements/evidence comparison, partial/comparable lifecycle costs, responsibility and exit gaps, one conditional recommendation or evidence task.
Do not route broad competitor discovery, staffing, demand validation, PRDs, legal/license/security acceptance, provider activation or application implementation here. Resolve those existing owners separately. Arm build-buy-analysis-stinger first using source catalog or installed selected-owner proof. Return report content to parent for local saving; no trial/purchase/account/message authority.
