# Library Packets Wasp Drone

**Drone:** [library-packets-wasp-drone](https://github.com/legioncodeinc/vibe-coding-tools/blob/v3.0.1/plugins/documentation-tools/agents/library-packets-wasp-drone.md)
**Stinger:** [library-packets-stinger](https://github.com/legioncodeinc/vibe-coding-tools/blob/v3.0.1/plugins/documentation-tools/skills/library-packets-stinger/SKILL.md)
**Command:** [library-packets](https://github.com/legioncodeinc/vibe-coding-tools/blob/v3.0.1/plugins/documentation-tools/commands/library-packets.md)
**Trigger policy:** on-demand

**Plugin owner:** `documentation-tools`. **Required selection:** wasp-nest-core. Resolve the selected installed owner before dispatch; use the source link for the canonical procedure.


## Domain

Turn an accessible source library into audience-specific document packets, with grounded claims, editable Markdown/Word, branded PDF and citations. The source coverage determines the breadth. The Drone owns the new packet and private proof records; the library remains read-only.

## Trigger phrases

- Turn this library into executive and team documents.
- Produce a branded document packet from these requirements and private docs.
- Create Markdown, Word and PDF briefs with source citations.
- Run library-packets.

## Do NOT route when

- The user needs source PRDs/IRDs or library scaffolding: use library-wasp-drone.
- The task is only internal narrative architecture knowledge: use knowledge-wasp-drone.
- The task is only a competitor workbook: use competitive-research-wasp-drone.
- The user asks to implement a proposed gap, publish or send a packet: route the separately authorized work to its owner.

## Inputs

An accessible library and agreed output location; subject/readers/decision; product account; public exclusions and source-release scope; research and branding choices where needed. Ask only unanswered questions from the Stinger intake. A plain chat may need library attachments and document tools rather than local-folder access.

## Outputs

Supported documents in Markdown, editable Word, PDF and audience-safe citation lists; a reader index; private inventory, source/claim/coverage maps, concrete gap findings and hash-bound every-page review. Unsupported documents remain explicitly deferred.

## Dispatch

At top level, arm the Drone with its paired Stinger path, scoped library/output files, user answers and output/inspection checks. It does not spawn a nested fleet. The orchestrator may assign separate research, writing or review lanes with explicit ownership when that improves the agreed packet.

Runtime is research/document (source-repository research, not shipped) production with no application-code commit. Independent source/publication and page review remain mandatory; a research-only label never waives them. No source mutation, paid account creation, dependency install, configuration change, external send or publication is implied.
