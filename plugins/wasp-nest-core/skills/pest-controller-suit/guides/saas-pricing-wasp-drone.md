# saas-pricing routing guide

**Plugin owner:** `software-economics-tools`. Requires Core and this selected owner.

## Domain

Recommend a provisional SaaS price/model from value evidence, costs and an explicit experiment.

## Trigger phrases

price my SaaS; seats vs usage; initial product price; pricing experiment.

## Do NOT route when

Payments owns billing implementation; Unit Economics owns arithmetic; no live price writes or proven willingness to pay without research.

## Inputs and outputs

Read the selected paired skill for its scoped intake. Reuse supplied decisions and ask only missing choices. Return one sourced/provisional recommendation, assumptions, actual verification and unresolved decisions. Do not invent rates, market demand, benchmarks or installed capabilities.

## Dispatch

Resolve `saas-pricing-stinger` through trusted Core's selected registry for installed work, or current catalog source_root for source work. Read it before dispatch; native delegation is used only when actually present. A supported direct-use fallback must be authorized and reported honestly. Cached paths are not selected capabilities. Advisory output grants no provider, code, configuration, customer-send, price-write or release authority.
