- Explain why this assertion failed.

Need the learning goal and stated behavior/input domain. Ask for missing expected behavior; do not invent it. Return a chat lesson, actual attempt and assistance, expectation source, observed receipt or NOT_RUN, one next exercise and understanding PENDING if no actual learner evidence.
