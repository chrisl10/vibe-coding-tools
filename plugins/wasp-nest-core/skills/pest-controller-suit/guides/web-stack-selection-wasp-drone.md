# web-stack-selection routing guide

**Plugin owner:** `web-development-tools`. Requires Core and this selected owner.

## Domain

Recommend one supported web framework from product, team and rendering constraints.

## Trigger phrases

choose web stack; React Vite vs SvelteKit; Next.js vs Vue; framework fit.

## Do NOT route when

Implementation goes to its actual owner; no full Next.js/Vue/Nuxt delivery claim from adjacent React/security owners; native UI and backend language choice remain separate.

## Inputs and outputs

Read the selected paired skill for its scoped intake. Reuse supplied decisions and ask only missing choices. Return one sourced/provisional recommendation, assumptions, actual verification and unresolved decisions. Do not invent rates, market demand, benchmarks or installed capabilities.

## Dispatch

Resolve `web-stack-selection-stinger` through trusted Core's selected registry for installed work, or current catalog source_root for source work. Read it before dispatch; native delegation is used only when actually present. A supported direct-use fallback must be authorized and reported honestly. Cached paths are not selected capabilities. Advisory output grants no provider, code, configuration, customer-send, price-write or release authority.
