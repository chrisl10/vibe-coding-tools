# Qualification examples

These are hypothetical exercises, not execution claims.

## Happy path

A proposed shared customer inbox has unknown external-actor authorization. The register separates supplied design facts from untested tenant isolation, makes cross-tenant denial a required acceptance case, and assigns the smallest validating check.

## Missing owner

No selected code-security reviewer covers the actual framework: retain discovery risks and mark code security unassessed, naming the missing coverage rather than substituting a generic score.

## Failure path

A vendor integration document contradicts the accepted permission contract: report the disputed boundary and stop dependent specification changes; keep unrelated assumption tests moving.
