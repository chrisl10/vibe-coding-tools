# Qualification examples

These are hypothetical exercises, not execution claims.

## Happy path

Validated appointment-reminder opportunity becomes one owner-configured reminder path with delivery failure visibility; advanced campaign automation is deferred. Library pins the accepted reminder event revision before separate provider/UI work.

## Missing owner

Core is selected but business-and-product-tools is absent: do not invent discovery/estimation roles. Preserve supplied scope and name the unavailable pair before drafting dependent recommendations.

## Failure path

No interview or assumption-test evidence exists: produce the proposed test and provisional scope; report that a validated build recommendation is unfinished.
