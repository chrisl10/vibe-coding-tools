# Compare lifecycle, interfaces and exit

Grounding: [purchasing](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/business-and-product-tools/skills/build-buy-analysis-stinger/references/research/raw/purchasing.md), [integration](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/business-and-product-tools/skills/build-buy-analysis-stinger/references/research/raw/integration.md), [export](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/business-and-product-tools/skills/build-buy-analysis-stinger/references/research/raw/slack-export.md), [terms](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/business-and-product-tools/skills/build-buy-analysis-stinger/references/research/raw/slack-terms.md) and [limits](https://github.com/legioncodeinc/the-wasp-nest-source/blob/main/packs/business-and-product-tools/skills/build-buy-analysis-stinger/references/research/raw/slack-limits.md). The worksheet fields below are an advisory adaptation, not a certification.

1. For each option, name who owns design decisions, source access, IP rights, configuration, identity administration, incidents, upgrades and restoration. Partner delivery must include handover and post-contract support questions. Buying software still needs an operating owner. Building still depends on languages, libraries, staff and hosting.
2. Map each integration: source/destination, required read/write action, authority, API/version/plan, app classification, documented limits, retry rules, data transformation, failure reconciliation and upgrade owner. A developer portal establishes documentation availability only. Runtime owners verify actual behavior under separately authorized scope.
3. Enumerate exit objects: records, files, history, configuration, identities, permissions and automations. For each ask whether export gives bytes or links, when available, who can request it, contractual access after termination, fees, mapping losses, destination support, restoration evidence and deletion obligations. A ZIP or API does not establish a functioning migration. Do not bypass product restrictions to fill a gap.
4. Use one supplied comparison horizon. Count acquisition/build, integration, migration, operating labor, subscription/usage, hosting, support/upgrades, review requirements and exit cash separately. Every number needs currency, period, source date and included/excluded scope. Unknown amounts stay unknown; do not convert blank values to zero.
5. Show comparable totals only for populated costs with the same horizon. Mark partial totals and exclusions. Owner labor is counted once, separately from cash when applicable; reused infrastructure is not automatically zero incremental cost. Pricing, Operating Cost and Services Quoting own specialist estimates. No universal AI speed factor, ROI, savings guarantee or invented vendor price.
6. Capacity Planning owns staffing scenarios; Security owns security assurance; legal/license owners determine contract and license applicability. Preserve their pending status. A salesperson's compliance statement or public terms page cannot close those reviews.

The vendor snapshots are counterexamples to broad portability/API claims, not a recommendation for or against Slack.
