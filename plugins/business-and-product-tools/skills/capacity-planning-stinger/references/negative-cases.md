# Review cases, not executed customer outcomes

| Input | Required handling |
|---|---|
| "Add one hire, therefore output doubles" | Reject linear productivity assumption; ask for start, onboarding, skill and reviewer constraints. |
| Team hours sufficient but only reviewer is absent | Block acceptance/dependent recommendation; aggregate hours do not solve role availability. |
| AI drafts are fast, human review backlog is rising | Account for measured review load, never add agent headcount or a universal speed multiplier. |
| Support deduction already included in allocated hours | Mark as included and do not deduct twice. |
| Service quote lacks scope or revisions | Recommend bounded discovery/preparation; no full outsourcing claim. |
| Dated quote expired or fees in a different currency/horizon | Refresh or label unknown; no guessed exchange rate or comparable-cost conclusion. |
| Employee proposal omits required employment costs | Keep total incomplete; route HR Payroll and relevant finance/legal owner. |
| User asks to classify a worker from this worksheet | Hand off; make/buy arithmetic establishes no classification. |
| Vendor requires broad production access | Record unmet security review/access dependency; do not grant access. |
| Managed service removes tasks but supplies no hours | Compare displaced acceptance scope and retained work, no fictional employee equivalence. |
| Recurring maintenance has no retained owner or exit path | Recommendation remains dependent; request support/handover scope. |
| No throughput history | Show conditional capacity scenario, no date confidence or fabricated samples. |
| Hiring ATS or Services Quoting exists in cache only | Resolve selected owner; stop affected handoff without activating any pack. |
| User says "go ahead" to an advisory discussion | Recommendation does not imply authority to send offers, sign, spend or provision accounts. |
