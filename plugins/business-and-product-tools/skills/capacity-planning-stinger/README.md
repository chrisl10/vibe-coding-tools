# Capacity planning

Produce one provisional operational recommendation for a founder or team deciding when to hire or buy services. It connects bounded demand, skill gaps, actual capacity and supplied dated quotes to current-team review, onboarding, support and exit work.

- [Measure capacity](guides/01-measure-capacity.md): inputs, comparability and bottlenecks.
- [Recommend make/buy](guides/02-recommend-make-buy.md): recommendation and handoffs.
- [Model](references/model.md), [worksheet](references/templates/worksheet.md), [fictional example](examples/make-buy.md), [negative cases](references/negative-cases.md).
- [Dated evidence digest](references/research/distillation.md), source identities and quote locators.

Runtime is local advisory preparation. It does not select a real candidate, commit to a vendor, classify a worker, provision access, send anything or perform payroll/procurement. Existing Estimation, Kanban Flow, Services Quoting, HR Payroll and Hiring ATS are complementary owners, resolved through trusted Core. No native installed availability is implied by source registration.
