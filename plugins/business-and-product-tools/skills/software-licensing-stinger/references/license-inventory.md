# Artifact and permission inventory
Fill each field with Observed, Supplied, Inferred or Unknown and its locator. Do not store secrets or personal data.

| Field | Evidence |
|---|---|
| Target and intended action | Use/change/convey/host; recipients and remote users |
| Artifact identity | Path, release/version/commit, byte hash, capture date |
| Component graph coverage | Direct/transitive/vendored/generated/unknown; actual artifact contents |
| License | Exact text, SPDX expression if known, exception/alternative, original source |
| Notices | Copyright/license/NOTICE and their actual inclusion path |
| Modification | Original versus changed files and supported diff |
| Boundary | Client/server/native/container; copy delivery, covered-work uncertainty |
| Source proposal | Corresponding Source inventory/offer path; unproved items |
| Separate terms | Fonts, icons, photos, data, models, APIs, patents, trademarks |
| Rights and authority | Actual holder/grant evidence, owner's task authorization, reviewer |
| Review | Open compatibility questions, applicable clause, counsel decision pending |
| Proposed action | Exact files/action and approval status; default no changes |

A fingerprint shows which bytes were reviewed. It is not proof that a permission was granted, a notice is sufficient, or a combined work is compatible.
